# Where things are in the UI

Read this for "where do I click" questions. Checked on 2026-11-16 against the pages named in brackets (under `https://docs.aws.amazon.com/accounts/latest/reference/`). Labels move; if the user's screen differs, believe the screen and the current page.

Two places matter:

- **AWS Settings** (`https://settings.aws.com`): projects, team, billing, spend limits, profile. From the AWS Management Console, choose **Manage projects**. After advanced features are active it is reachable only at the URL.
- **AWS Management Console**: the resources inside one project. The current project's name is in the upper right. Before activation the console is a simplified view with no Region selector.

| Task                                              | Path                                                                                                                                                                                                                                                                                                                               | Page                              |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| See a project's Region and account ID             | AWS Settings → Project → Overview → Additional info                                                                                                                                                                                                                                                                                | `project-regions.html`            |
| Create a project                                  | AWS Settings → Project → Create project                                                                                                                                                                                                                                                                                            | `create-project.html`             |
| Open a project's console                          | AWS Settings → choose the project → **Create and manage cloud infrastructure**                                                                                                                                                                                                                                                     | `switch-projects.html`            |
| Switch project from the console                   | Project name (upper right) → Switch project → choose an active session                                                                                                                                                                                                                                                             | `switch-projects.html`            |
| Connect an AI coding tool                         | AWS Settings → project → Create and manage cloud infrastructure → Use your AWS credentials with AI coding tools → Copy agent prompt                                                                                                                                                                                                | `connect-ai-coding-tool.html`     |
| Invite team members                               | AWS Settings → Team → Invite new team member                                                                                                                                                                                                                                                                                       | `invite-team-members.html`        |
| Remove a team member                              | AWS Settings → Team → select → Remove                                                                                                                                                                                                                                                                                              | `remove-team-members.html`        |
| Upgrade to the Paid plan                          | AWS Settings → Billing → Upgrade                                                                                                                                                                                                                                                                                                   | `upgrade-account.html`            |
| Set a spend limit                                 | AWS Settings → Billing → Cost by project → Set limit for a project                                                                                                                                                                                                                                                                 | `create-spend-limit.html`         |
| Root-only fixes (deny-all bucket or queue policy) | Project console → IAM → Root access management                                                                                                                                                                                                                                                                                     | `aws-actions-project-owners.html` |
| See who changed something                         | Project console → CloudTrail → Event history → `onBehalfOf`                                                                                                                                                                                                                                                                        | `monitor-your-project.html`       |
| Close a project                                   | AWS Settings → project → Close project                                                                                                                                                                                                                                                                                             | `close-project.html`              |
| Activate advanced features                        | AWS Settings → Projects → Actions → Explore advanced features (`settings.aws.com/projects/activate-advanced`, seen 2026-11-16): team name, management account email and its code, Review and complete activation, type "Confirm activation", Activate; the progress dialog says it takes up to 5 minutes and to keep the page open | `activate-advanced-features.html` |
| Edit SCPs or RCPs (after activation)              | AWS Settings → Projects → Manage this organization → Manage policies                                                                                                                                                                                                                                                               | `remove-org-policies.html`        |
| Manage workforce (after activation)               | AWS Settings → Projects → Actions → Manage team (opens IAM Identity Center)                                                                                                                                                                                                                                                        | `manage-workforce-members.html`   |
| Change identity source (after activation)         | AWS Settings → Projects → Manage this organization → Change identity source                                                                                                                                                                                                                                                        | `change-identity-source.html`     |
| Password, MFA, profile                            | AWS Settings → Manage profile (opens the AWS Builder ID profile)                                                                                                                                                                                                                                                                   | `use-aws-settings.html`           |
